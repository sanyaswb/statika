# statika

1. Введи IP, коментар, MAC та сервер і натисни «+ Додати». Значення залишаться в полях для наступного запису.
2. Щоб використати MAC зі старого файлу, натисни іконку імпорту біля поля MAC та обери `.rsc` або `.txt`. Програма збере унікальні значення `mac-address=...`. Якщо таких полів немає, вона знайде MAC-адреси за форматом із двокрапками, дефісами або крапками. Список можна переглянути під полем MAC.
3. Якщо імпортований файл має `comment="..."`, можеш увімкнути «Оригінальні з файлу» біля поля коментаря. Програма збереже кожен коментар із відповідним MAC, а ручне поле стане неактивним. Якщо частина MAC не має коментаря, відкриється вікно з пропозицією назви «Без назви»; її можна змінити. У файлі вона з'явиться як `comment="==Без назви=="` або з обраною назвою. Якщо коментарів у файлі немає взагалі, прапорець неактивний і коментар треба ввести вручну.
4. Після імпорту введи лише першу IP-адресу, сервер і, якщо прапорець вимкнений, коментар. Натисни «Згенерувати». Програма сама визначить останню адресу за кількістю MAC і покаже діапазон під полем IP. Наприклад, для 100 MAC початкова адреса `192.168.10.2` дасть діапазон до `192.168.10.101`. Перехід від `.255` до `.0` наступного октету відбувається автоматично. Повторне генерування замінює попередній результат.
5. За потреби натисни Reset, щоб очистити поля введення та вийти з режиму імпорту. Уже згенеровані записи залишаться.
6. Завантаж файл кнопкою «Завантажити .rsc» або «Завантажити .txt».
7. Перенеси файл у Files на MikroTik.
8. Відкрий New Terminal і виконай `import` з назвою файлу.

Під генератором можна оцінити програму від 1 до 5 зірок і залишити коментар. Коментар з'явиться біля програми під випадковим кутом і залишиться на сторінці до її оновлення. Якщо коментар — «дякую» (у будь-якому регістрі, зі знаками оклику або без них), з'явиться відповідь «Дівчина с пиздякою!». Відгуки працюють лише в поточній вкладці й не надсилаються на сервер.
