# statika

1. Введи IP, коментар, MAC та сервер і натисни «+ Додати». Значення залишаться в полях для наступного запису.
2. За потреби натисни Reset, щоб очистити поля введення.
3. Завантаж файл кнопкою «Завантажити .rsc» або «Завантажити .txt».
4. Перенеси файл у Files на MikroTik.
5. Відкрий New Terminal і виконай `import` з назвою файлу.

Відкрити сайт - [https://sanyaswb.github.io/statika/]
