# statika

1. Введи IP, коментар, MAC та сервер і натисни «+ Додати». Значення залишаться в полях для наступного запису.
2. Щоб використати MAC зі старого файлу, натисни іконку імпорту біля поля MAC та обери `.rsc` або `.txt`. Програма збере унікальні значення `mac-address=...`. Якщо таких полів немає, вона знайде MAC-адреси за форматом із двокрапками, дефісами або крапками. Список можна переглянути під полем MAC.
3. Після імпорту введи лише першу IP-адресу, коментар і сервер та натисни «Згенерувати». Програма сама визначить останню адресу за кількістю MAC і покаже діапазон під полем IP. Наприклад, для 100 MAC початкова адреса `192.168.10.2` дасть діапазон до `192.168.10.101`. Перехід від `.255` до `.0` наступного октету відбувається автоматично. Повторне генерування замінює попередній результат.
4. За потреби натисни Reset, щоб очистити поля введення та вийти з режиму імпорту. Уже згенеровані записи залишаться.
5. Завантаж файл кнопкою «Завантажити .rsc» або «Завантажити .txt».
6. Перенеси файл у Files на MikroTik.
7. Відкрий New Terminal і виконай `import` з назвою файлу.
